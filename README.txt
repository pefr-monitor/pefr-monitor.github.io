

v2.8 추가사항
- 초기 PEF1~3의 상위 두 값 차이가 40 L/min 초과하면 PEF4·PEF5 추가 측정칸 표시
- 추가 측정을 시작한 뒤에는 반복성 기준이 충족되어도 PEF4·PEF5 입력칸과 기록이 사라지지 않음
- PEF4만 입력한 경우에도 PEF5 입력칸을 계속 유지
- PEF4·PEF5 값 및 각각의 측정시간을 계속 화면에 표시
- 최고값은 PEF1~5 전체 측정값 중 최고값으로 계산


v2.9 개선사항
- '하루 4회 측정'과 '한 측정시간대에서 3~5번 불기' 용어를 명확히 분리
- 각 입력 카드 제목을 '오늘 n번째 측정시간대'로 변경
- PEF 1~5를 'n번째 불기'로 표시
- 최초 3회 상위 두 값 차이 ≤40 L/min: '측정 완료 · 반복성 기준 충족'
- 최초 3회 상위 두 값 차이 >40 L/min: PEF4·PEF5 추가 측정 안내
- 총 5회 후 상위 두 값 차이 ≤40 L/min: '측정 완료 · 반복성 기준 충족'
- 총 5회 후에도 >40 L/min: '측정 완료 · 반복성 기준 미충족' 경고
- 반복성 미충족이어도 총 5회 중 최고값을 해당 측정시간대 PEFR로 기록
- CSV에 측정시간대번호, 실제측정횟수, 상위2값차이, 반복성상태 추가
- 기존 기록/localStorage 키 유지
