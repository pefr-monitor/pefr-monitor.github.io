PEFR 모바일 정적 웹앱 v2.2

구성
- index.html
- manifest.webmanifest
- service-worker.js

주요 기능
- 모바일 우선 '오늘 측정' 화면
- 3/4주 자동 생성, 4회/일 기본 측정
- 각 측정 3회 입력 후 최고값 자동 계산
- 상위 두 측정값 차이 >40 L/min이면 4·5회 추가측정 칸 자동 표시
- 작업상태/측정장소/증상/기관지확장제 기록
- 휴대폰 브라우저 localStorage 자동저장
- 전체 진행률, 완료일수, 오늘 완료횟수
- 주차별 지난 기록
- 작업일/비작업일 평균 PEFR
- 일중변동률 D.V. = (Max-Min)/Mean ×100
- PEFR 추이 및 D.V. 그래프
- CSV 저장, 요약 인쇄/PDF, 파일 공유, 담당자 메일 열기
- JSON 중간백업/복원
- PWA용 manifest/service worker 및 오프라인 캐시
- 브라우저 알림 권한 기능(단, 백그라운드 예약 알림은 보장하지 않음)

배포
GitHub Pages 등 HTTPS 정적 호스팅 루트에 세 파일을 그대로 업로드하면 됩니다.
index.html이 저장소 루트에 있어야 합니다.

주의
- 입력 건강정보는 별도 서버로 전송하지 않고 해당 브라우저 localStorage에 저장합니다.
- 브라우저 데이터 삭제/시크릿 모드/휴대폰 교체 시 유실될 수 있습니다.
- 알림 기능은 브라우저/OS 제약으로 페이지가 완전히 종료된 상태의 정시 알림을 보장하지 않습니다.
- 그래프와 D.V. 요약은 참고용이며 Oasys 전문 소프트웨어의 진단 점수를 대체하지 않습니다.
- 실제 근로자 적용 전 기관 개인정보/정보보안 검토가 필요합니다.
