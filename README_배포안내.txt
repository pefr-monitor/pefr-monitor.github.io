PEFR 정적 웹 기록시스템 v1.0

■ 구현된 흐름
PEFR 웹페이지 → 정적 웹호스팅 → 링크 문자 발송 → 근로자 휴대폰에서 3~4주 기록
→ CSV 또는 PDF 저장 → 담당자(kyeong85@comwel.or.kr) 메일 작성 화면 열기 → 파일 첨부 후 전송

■ 데이터 저장 방식
- 입력값은 웹호스팅 서버나 별도 DB에 저장하지 않습니다.
- 근로자가 사용 중인 휴대폰의 해당 브라우저 localStorage에 자동저장됩니다.
- 같은 휴대폰 + 같은 브라우저 + 같은 웹주소로 다시 접속하면 이어서 작성됩니다.
- 브라우저 데이터 삭제, 시크릿 모드, 휴대폰 교체 시 기록이 사라질 수 있으므로 '중간 백업(JSON)' 기능을 넣었습니다.

■ 사용방법
1. index.html을 정적 웹호스팅 공간에 업로드합니다.
2. 생성된 HTTPS 주소를 문자로 보냅니다.
3. 근로자는 링크를 눌러 측정 시작일과 측정기간을 설정하고 '측정기간 생성'을 누릅니다.
4. 매일 PEFR 3회 값과 작업상태·장소·증상·약물 사용을 기록합니다.
5. 입력할 때마다 자동저장됩니다.
6. 종료 후 'CSV 저장' 또는 'PDF로 저장/인쇄'를 이용합니다.
7. '담당자 메일 열기'를 누르면 수신자가 kyeong85@comwel.or.kr로 자동 입력됩니다.
8. 저장한 CSV/PDF를 첨부하여 전송합니다.

■ 문자 예시
[직업환경연구원 PEFR 연속측정 안내]
아래 링크에 접속하여 안내에 따라 3~4주간 최대호기유속(PEFR)을 기록해 주세요.
https://YOUR-HOST/pefr/

기록은 사용 중인 휴대폰 브라우저에 자동 저장됩니다.
측정 종료 후 화면의 'CSV 저장' 또는 'PDF로 저장'을 이용한 뒤,
'담당자 메일 열기'를 눌러 기록파일을 제출해 주세요.

■ 배포 시 주의
- 반드시 HTTPS 웹주소 사용을 권장합니다.
- 실제 운영 전 기관 정보보안·개인정보 담당부서 검토가 필요합니다.
- 이 페이지 자체는 입력한 건강정보를 서버로 전송하도록 구현되어 있지 않습니다.
- 단, 웹호스팅 사업자는 일반적인 접속 로그(IP, 접속시각 등)를 보유할 수 있으므로 기관 정책을 확인하십시오.
